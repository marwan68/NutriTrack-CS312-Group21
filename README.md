# NutriTrack — CS312 Group 21

## Project Overview

NutriTrack is a C# Windows Forms desktop application designed to help users track their nutrition, daily meals, water intake, weight and health goals.

## Technologies Used

- C#
- .NET 8
- Windows Forms
- GDI+
- Object-Oriented Programming
- Event Handling
- LINQ

## Main Features

- Dynamic dashboard
- Meal logging and management
- Expandable meal categories
- Water intake tracking
- Weight tracking
- Calorie and macro goal tracking
- Dynamic analytics and reports
- Profile and goal management

## Windows Forms Controls & Event Handling

- Buttons and Click events
- TextBox and keyboard input
- ComboBox and SelectedIndexChanged events
- NumericUpDown controls
- DateTimePicker controls
- DataGridView
- Dynamic data updates
- Form navigation

## GDI+ / Graphics / Visualization

- Dynamic weight line charts
- Calorie donut charts
- Macro bar charts
- Rounded progress bars
- Dynamic calorie trend graphs
- Custom graphics using OnPaint
- Anti-aliasing and double buffering
- Automatic graphics redrawing

## Important Classes

- **TrackingData.cs:** Shared application data and calculations.
- **DynamicChart.cs:** Custom dynamic GDI+ charts.
- **RoundedProgressBar.cs:** Custom rounded progress bars.
- **Navigator.cs:** Navigation between forms.
- **WaterLogForm.cs:** Water intake logging.

## How to Run

1. Clone or download the repository.
2. Open NutriTrack.sln in Visual Studio.
3. Rebuild the solution.
4. Press F5 to run the application.
